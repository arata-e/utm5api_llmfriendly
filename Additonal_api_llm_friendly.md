# UTM5 API Section: Additonal

This document describes the endpoints for the 'Additonal' API section for UTM5 isp billing system by Netup Co.

## Endpoint: Additonal - Delete radius session by slink_id
### Details:
- **Method:** `DELETE`
- **URL:** `{{api_url}}api/additional/radius_session`
### Parameters: None
### Example Response:

HTTP/1.1 200 OK
  {
    "result": "ok"
  }
```
